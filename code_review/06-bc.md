## Notes and open questions
- `exy_strain_rates` is the tensor component; code doubles it to get dvx/dy. Comment is right.
- Default velocity BC reads `bcp` ghosts to leave the normal velocity free where a pressure
  BC is set. Only z ghosts are ever set, so the x/y checks are always true (harmless).
- TPC shear BC uses `SIZE_CELL(j, sy, ...)` with the ghost-range start. Index is off by one
  on the last y-rank, but the boundary ghost node is placed one cell size out, so the value
  is the same. Harmless.
- Bezier block is linear interpolation between path points, not a Bezier curve (comment block
  explains why). Header still sizes `path` for 3n-2 points and calls it Bezier.
- 2D-path Bezier blocks leave vz free inside the block (WARNING comment in bc.h).
- Whole BCCtx is fwrite'd with LaMEMLib, so all inputs survive restart; only the function
  `static` in BCGetVelins does not (S-011).
- CompensatingInflow (face 5): net inflow is 2*velin*(top-bot) per unit width; balance must
  come from user `bvel_velbot`/`bvel_veltop` (default 0) or an open top. Not checked (N-012).
